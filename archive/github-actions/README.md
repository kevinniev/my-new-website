# Archived GitHub Automation Definitions

These workflow definitions were moved out of `.github/workflows/` on 2026-09-10 as part of the AVfreelance external-automation zero-execution reset.

They are retained solely as historical reference. GitHub Actions does not discover or execute workflow files from this directory. Restoring any workflow requires a separate review, explicit approval, and fresh validation of its side effects, credentials, trigger, idempotency, and rollback controls.

No workflow in this archive is authorized to post, email, message, alter marketplace data, invoke providers, or perform financial actions.
