# Read-Only Vercel Cron Candidate

`vercel-read-only-crons.json` is a review artifact, not the root `vercel.json` configuration. The root configuration deliberately has no cron definitions and the Vercel Cron Jobs project feature remains disabled.

If promoted after separate approval, these routes remain fixture-only review manifests. Promotion does not authorize provider calls, social publishing, messages, email, hiring, payments, payouts, or production data mutations.
